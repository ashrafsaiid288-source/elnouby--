# النوبي — سيستم الأقساط

## تشغيل للتطوير
npm install
npm start

## بناء ملف exe (على ويندوز)
npm run dist
الملفات بتطلع في فولدر dist:
- Al-Nouby-Setup-1.0.0.exe  (برنامج تثبيت)
- Al-Nouby-Portable-1.0.0.exe (يشتغل من غير تثبيت)

## البيانات
بتتحفظ في: %APPDATA%\Al-Nouby\nouby-data.json
ونسخة احتياطية أوتوماتيك كل يوم في فولدر backups (آخر 30 يوم).
